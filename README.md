# Lumen System - Website Oficial

Website corporativo moderno e de alta performance para a **Lumen System**.

## Tecnologias
- HTML5 / CSS3 (Design moderno com Glassmorphism, Modos Responsivos e Animações)
- JavaScript ES6+
- Node.js / Vite

## Como Rodar Localmente
```bash
npm install
npm run dev
```
